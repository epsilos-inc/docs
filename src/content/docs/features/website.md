Ready Website packages are for corporate and showcase sites without an online store.
Feature availability varies by package tier; see [Pricing](/pricing/packages).

## Visual page builder

- Drag-and-drop layout designer that works directly on the live site
- 4-level nested grid: **Grid → Row → Column → Module**
- 35+ ready-made modules: sliders, hero banners, image galleries, dynamic menus,
  heading and text blocks, video popups, pricing tables, countdown timers, contact
  forms, social media widgets, maps, tab panels and more
- Design wizard and ready-made sections
- Inline editing: edit controls on components directly on the live page
- Reusable header / footer sections
- Menu / navigation builder

## Themes

- Large library of mobile-responsive corporate and showcase themes
- Tuned for 30+ sectors
- Instant switching from the panel without touching content or data

## Content

- Blog system (posts, categories, tags, comments)
- Content management panel
- Product / catalog listing (non-transactional)
- Multi-language system with RTL support and automatic redirect by browser language

## Communication

- Contact forms
- Live chat and messaging-app integration

## SEO and analytics

- SEO tools and configuration
- Rich snippet / structured data (Schema.org) and Open Graph tags
- Per-page meta title and description
- Search Console and Analytics integration
- Category / tag / brand / filter linking structure
- UX and clarity analysis

## Media and performance

- Automatic image optimization
- CDN delivery
- Bulk import via Excel

## AI tools

- AI-assisted content generation
- Server-side AI for interface customization

## Integrations and extensibility

- Google Ads campaign setup
- Custom code injection slots (head, before `</head>`, before `</body>`) for GTM,
  chat widgets, etc.
- SMTP email

## Hosting and operations

- Managed hosting with SSL, email accounts (POP3 / IMAP) and weekly / monthly
  backups, or deploy on your own infrastructure through the licence system

## Support

- Priority support and one-on-one training (by tier)
